> [!abstract] 
> There are *two types* of study evaluation:
> + Analytical:
> 	+ Determining proof/truth;
> 	+ Finding solutions to mathematical models.
> + Empirical:
> 	+ Evidence-based;
> 	+ Extracting a truth from observed findings.
## Empirical Research Methods
+ Controlled experiments;
+ Case studies;
+ Survey research;
+ Ethnographies;
+ Action research;
+ Etc.

| Quantitative                                                                      | Qualitative                                                   |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Objective                                                                         | Subjective                                                    |
| Research questions include: "how many?", "strength of association?", "is better?" | Research questions include: "what?" "why?"                    |
| "Hard" science                                                                    | "Soft" science                                                |
| Test theory                                                                       | Develops theory                                               |
| Measurable (in numeric terms)                                                     | Interpretive                                                  |
| Report statistical analysis                                                       | Report rich narrative, individual, up to interpretation       |
| Subjects                                                                          | Participants                                                  |
| Establishes relationships, causation                                              | Describes meaning, discovery                                  |
| Generalisations leading to prediction, explanation, and understanding             | Patterns and theories developed for understanding             |
| Highly controlled setting: experimental setting (outcome oriented)                | Flexible approach: natural setting (process oriented)         |
| Sample size $n$                                                                   | Sample size is not a concern; seeks an "informal rich" sample |
| "Counts the bugs"                                                                 | Provides information as to "which bugs are worth counting"    |
