#notes 

A **dependency grammar** is essentially a [[First-Order Syntax#Parse Trees|First-Order Syntactical Parse Tree]] but for natual language. We have *nodes* as **tokens**; *edges* as **syntactic relationships between nodes**.

We assume that syntactic relationships are between *pairs* of lexical terms.

![[Dependency Grammars.png]]

We can use the `stanza` Python package to analyse these.
