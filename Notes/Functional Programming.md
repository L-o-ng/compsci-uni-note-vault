A **side effect** is a hidden state change that results from a function modifying or relying upon objects external to its parameter list.
A **pure function** is a function that takes all its inputs as arguments and produces all its outputs as results; it has no *side effects*.
A **functional** programming language:
+ Encourages using function *application* and *composition* as basic building blocks;
+ Forbids variable assignment and side effects;
+ Makes *reasoning* about code simpler.
