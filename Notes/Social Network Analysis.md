#definition 

![[Social Network Analysis.png]]

A **social network** is a [[Graph Theory|Graph]] $G=(V,E)$ with $V=\{ \text{entities} \}$, often *people*, and $E=\{ \text{social relationships} \}$.
We can measure:
+ Centrality Metrics: how *important* is a node to a network?
+ Community Detection: what interconnected subgroups of nodes exist with more internal connnections?
