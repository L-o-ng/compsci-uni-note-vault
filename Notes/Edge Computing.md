Web caches are effective when deployed closer to clients at the **edge** of the network.
**Edge Computing** is a paradigm where applications run on servers located at the edge of the network.
## Benefits
+ Significantly lower latency than remote cloud servers;
+ Higher bandwidth;
+ Can tolerate network or cloud failures.

It also complements cloud computing: cloud providers offer edge servers as well as cloud servers.
