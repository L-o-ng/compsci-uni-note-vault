#definition 

**Unicode** is a *universal computing standard* that assigns a unique numerical value called a *code point* to every character, symbol and emoji. It is important to note that Unicode is **not** an encoding.

An **encoding** is a well-defined method for turning a string of characters into a sequence of bytes.

One example of an *encoding* is **UTF-8**. This is effectively the *default* encoding, replacing ASCII. It is a 1:1 mapping between byte sequences and code points, with variable length per code point.
