Once you have determined one from many [[Research Methodologies]], you must consider how to ensure the **reliability** and **validity** of the study. This must be done *early*, as not considering this can undermine all discoveries.
## Reliability
+ How close are repeated measurements to each-other?
+ How consistent are these repeated measurements?

A measurement/experiment can be said to be reliable if you obtain the same result if you repeat it many times.
### Assessing Reliability

| Type                   | Consistency                                                                                                          | Example                                                                                | Assessment                                                                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Test-retest (external) | Determines the reliability of the test measurements and results over time.                                           | Measuring a person's height should give the same result no matter when it is done.     | A good indicator of reliability is a strong correlation ($r > 0.8$) between the same test given to the same subjects over time.                        |
| Inter-rater (external) | Determines the reliability of the test measurements and results gathered by different researchers.                   | Three doctors should get the same body temperature result for the same person.         | Different people should give strongly correlated results.                                                                                              |
| Internal               | How consistent is the measurement? Do you get the same results if you use different tests to measure the same thing? | The doctor should get the same temperature if using a thermometer under arm or orally. | Measure the same variable twice in different ways. A person who identifies as confident should also have more positive things to say about themselves. |

## Validity
Validity measures how well the findings from a study reflect that which they are measuring.
A high validity means that the results correspond to the real thing.
![[Research Reliability and Validity.png]]
### Assessing Validity

| Type                   | Consistency                                                  | Example                                                                                         |
| ---------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| Construct (Content)    | Does the test relate to high-level theories (top-down)?      | Measurements should clearly relate to theories if there is strong validity.                     |
| Face (Content)         | Does the test appear to test what it aims to test?           | It should be clear that the test is measuring what it is supposed to.                           |
| Concurrent (Criterion) | Does the test relate to an existing similar validated test?  | Creating your own questionnaire to determine IQ should give the same results as previous tests. |
| Predictive (Criterion) | Does the test predict performance in a later developed test? | Can algorithmic performance in Test 1 be used to predict similar performance in Test 2?         |
